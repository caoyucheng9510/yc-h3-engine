# 四通道实测性能与成本基线参考

本文档整理自 2026-11-20 至 2026-11-25 在真实生产任务与压测中采集的 MiniMax-H3 实测数据，已剔除所有个人账号、私有余额与个人套餐实付价格，保留原始计费单位、样本量、日期与计时起止口径，供选型参考。

## 一、跨通道横向选型对比（`jinyu-hybrid` `1664×928` · 12 步）

| 通道 / 硬件 | 采集日期与样本量 | 规格 | 计时口径与实测耗时 | 原始计费单位 / 公开费率参考 | 核心结论 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **RunningHub Plus 48GB** | 2026-11-24–25（多镜样本） | `1664×928` · 12 步 · 5s / 11s（纯图或图音） | 端到端交付中位数：5s 约 `135–151s`；11s 约 `490s` | Plus 机型参考约 `0.23 积分/运行秒`（实际以接口回报 `chargedPoint` 为准） | 比 Colab `A100-80` 快 20%–40%；零运维、无需开关机，适合主力生产 |
| **晨羽按次 API（5090）** | 2026-11-24（4 单样本：5s/7s/11s） | `1664×928`（1.5 MP）· 5s–11s（无参考视频） | 纯推理 `2.15–4.81 min`；含平台内容审查排队总墙钟 **`37–44 min`**（审查等待约 `20–30+ min`） | 公开费率：`0.12 CNY/运行分钟`（算力卡）+ `0.03 CNY/次`（现金）；4 单实扣 **`¥0.29` / `¥0.34` / `¥0.46` / `¥0.61`** | 排队与内容审查期不扣算力费，单条成本最低；但墙钟长且无远端取消，仅适合不赶时间的零星补镜 |
| **Colab `A100-80`（80 GiB）** | 2026-11-25（7 单样本，全无部分加载） | `1664×928` · 12 步 · 4.5s–15.1s | 暖跑纯推理见下表（5.2s 约 `250.6s`，11.5s 约 `607.8s`） | 实测实例费率 `10.99 CU/hr`（不含冷启动下载时间） | 适合已有 CU 额度内连续批跑纯图 5–11s 镜头；不建议批量跑 `10s+` 视频参考 |
| **Colab `G4-96`（Blackwell 96 GiB）** | 2026-11-20（上游 WorldForge 基线） | 历史旧配方 `1344×768` · 12 步（非 SelfLift） | 暖跑纯推理：10s 纯图 `173–180s`；10s + `<Video 1>` `807s` | 实测实例费率 `10.05 CU/hr`（纯图约 `0.49 CU`，视频参考约 `2.26 CU`） | 有 G4 库存时优先 G4：96 GiB 是唯一可开 `--highvram` 跑默认 `heretic` 编码器的卡型 |

> **为什么 48GB 的 RunningHub Plus 反而比 80GB 的 Colab A100-80 快？**
> MiniMax-H3 关闭 `--highvram` 后会在文本编码阶段结束即卸载约 `27 GB` 编码器，采样期活跃显存小于 48 GB，因此实际推理速度主要取决于 GPU 架构代差与 TensorCore 算力，而非单纯显存容量。

## 三、受管 GPU 显存档位与冷启动说明

| 显存档位 | 代表卡型 | `jinyu-hybrid` / `jinyu-combat` 上限 | 说明 |
| :--- | :--- | :--- | :--- |
| **Tier 1（≥75 GiB）** | Colab `G4-96` / `H100-80` / `A100-80`；晨羽 `6000D-84G` | `1664×928`（1.5 MP）/ `15s` | 仅 ≥90 GiB（如 G4-96）开启 `--highvram`；80 GiB 卡默认关闭 `--highvram` 防 OOM |
| **Tier 2（36–74 GiB）** | `A100-40`；晨羽 `nGPU-48GB` | `1664×928` / `15s` | 要求主机 RAM ≥ 48 GiB；40 GiB 卡长镜存在重度卸载与解码 OOM 风险 |
| **Tier 3（20–35 GiB）** | `L4-24`；晨羽 `5090`（32 GiB） | `1024×544` / `8s` | 省略尺寸默认请求 `1664×928` 会在 Tier 3 预检 `block`，须显式传合法尺寸 |
| **Tier 4（<20 GiB）** | `T4-16` | 默认阻断 | 单底模大于整卡显存，不适合生产 |

- **冷启动权重下载**：匿名从 HuggingFace 拉取完整金鱼权重（约 40–50 GB，含 SHA-256 校验）在云端实测吞吐约 `141–194 MB/s`（约 4–5 分钟）。晨羽独占 GPU 将权重缓存在持久盘 `/usrdata/yc_models`（与私有镜像各有 50 GB 免费额度，超额按官方公布 `¥0.00036/GB/小时` 计费），可通过 `yc-h3 gpu save-image --backend chenyu` 保存私有镜像加速后续冷启。
- **台账折算配置**：如需在预检与 `yc-h3 ledger summary` 中自动估算人民币，可在 `~/.yc-h3-engine/.env` 填入你实际购买套餐的 `RUNNINGHUB_CNY_PER_POINT` 与 `COLAB_CNY_PER_CU`（留空则仅按原始积分/CU 记账）。
